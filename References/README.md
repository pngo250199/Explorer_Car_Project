## References

- [Digilent Zybo Z7](https://github.com/Digilent/Zybo-Z7)
  - Primary open-source hardware/software reference used to validate the Zybo Z7 HDMI and VDMA pipeline.

- [Digilent Zybo Z7 Software](https://github.com/Digilent/Zybo-Z7-SW)
  - Reference Vitis software for HDMI input/output, video capture, display control, dynamic clocks, and framebuffer management.

- [AMD/Xilinx Embedded Software](https://github.com/Xilinx/embeddedsw)
  - Official AMD/Xilinx drivers and examples, including AXI VDMA configuration and memory-to-stream / stream-to-memory transfers.
